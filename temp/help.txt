# AI-Powered Personal Knowledge Workspace & Automation Hub (Free/Open Source)

## Overview
A web platform where users can upload, organize, and search files, ask questions about their content, and automate file operations using natural language—all powered by FastAPI, MongoDB, open-source LLMs (like Llama 3 via Ollama), and a modern frontend. No paid APIs required!

---

## Step-by-Step Approach

### 1. Prerequisites
- Python 3.8+
- Node.js (for frontend, optional)
- MongoDB Atlas (free tier) or local MongoDB
- [Ollama](https://ollama.com/) (for running LLMs locally)

---

### 2. Backend Setup (FastAPI)
#### a. Project Structure
```
backend/
  app.py
  requirements.txt
  ...
```

#### b. Install Dependencies
```sh
pip install fastapi uvicorn pymongo python-multipart requests
```

#### c. Run Ollama and Pull a Model
```sh
ollama pull llama3
ollama serve
```

#### d. Example FastAPI Endpoint to Use LLM
```python
import requests
from fastapi import FastAPI

app = FastAPI()

@app.post("/ask-ai")
def ask_ai(prompt: str):
    response = requests.post(
        "http://localhost:11434/api/generate",
        json={"model": "llama3", "prompt": prompt}
    )
    return {"response": response.json()["response"]}
```

#### e. Add File Upload, List, and Automation Endpoints
- Use your current endpoints for file upload and MongoDB storage.
- Add endpoints for file search, semantic Q&A, and automation.

---

### 3. Document Q&A and Semantic Search (Free)
- Use [Haystack](https://haystack.deepset.ai/) or [LlamaIndex](https://llamaindex.ai/) for RAG (retrieval-augmented generation) over your files.
- Both can work with local LLMs (Ollama) and index PDFs, docs, images (with OCR).

#### Example: Simple Haystack Pipeline
```sh
pip install farm-haystack[all]
```
- See Haystack docs for connecting to local LLMs and indexing files.

---

### 4. Frontend Setup (Optional, but Impressive)
- Use React, Vue, or Svelte for a modern UI.
- Features: drag-and-drop upload, chat interface for AI, file browser, automation dashboard.
- Use `fetch` or `axios` to call FastAPI endpoints.

---

### 5. Automation/Agentic Actions
- Write Python functions for file management (move, rename, merge PDFs, etc.).
- Register these as FastAPI endpoints.
- Use LangChain (free) to orchestrate agentic workflows with your local LLM.

---

### 6. Security & Best Practices
- Use authentication (JWT, OAuth) for sensitive actions.
- Validate and sanitize all user input.
- Log all automation actions for auditability.

---

### 7. Example User Stories
- "Upload all my invoices, then ask: 'Which clients paid late last year?'"
- "Find all scanned receipts, extract totals, and generate an expense report."
- "Move all files related to 'Project X' into a new folder and share with my team."
- "Summarize all meeting notes from March and email me the summary."
